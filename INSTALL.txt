=======================
STEP-BY-STEP INSTALL
=======================

STEP 1: File Upload
-------------------
- thermal-printer.js ko apne GitHub repo ke ROOT folder mein daal do
  (jahan index.html hai usi folder mein)


STEP 2: index.html mein 3 changes
---------------------------------

A) <head> section mein yeh line add karo:

<script type="module" src="./thermal-printer.js"></script>


B) thermalPrintBtn button ka onclick change karo

DHUNDO (Ctrl+F se):
id="thermalPrintBtn"

USKO REPLACE KARO isse:

<button class="btn" id="thermalPrintBtn" style="margin-top:0; background:#5b4636; color:#fff; display:none;" onclick="printThermalBluetooth()">🧾 Print on Bluetooth Printer</button>


C) printer-integration.js ka pura content
   index.html ke last <script> tag ke END mein paste kar do
   (saare functions ke baad, </script> se pehle)


STEP 3: Test
------------
1. Chrome browser (Android recommended) se PWA kholo
2. Printer ON karo
3. Fees page → kisi fee pe "Print" dabao
4. Modal mein "🧾 Print on Bluetooth Printer" button dabao
5. Device list se HiLabel_DEC7 select karo
6. Receipt print ho jayegi
